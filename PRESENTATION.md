# 🟠 SaylorWatchBot

## Telegram-бот мониторинга покупок Bitcoin крупными игроками

**Учебный проект**

Premium crypto intelligence в Telegram

---

## 📌 Идея и проблема

**Проблема:** новости о покупках BTC крупными игроками (Strategy / MicroStrategy) появляются разрозненно, с задержкой и без удобной подачи.

**Решение:** Telegram-бот, который:

- автоматически отслеживает казну BTC компании **Strategy**
- мгновенно присылает уведомления о **покупках и продажах**
- показывает аналитику: средняя цена, затраты, бумажная прибыль (PnL)
- оформляет сигналы как **визуальные карточки** в стиле Bloomberg / Arkham

**Целевая аудитория:** крипто-инвесторы, трейдеры, аналитики, медиа-каналы.

---

## 🎯 Цели проекта

1. Научиться работать с **внешними API и парсингом сайтов**
2. Построить **асинхронное приложение** на Python (asyncio)
3. Реализовать **Telegram-бота** с понятным UX
4. Освоить **деплой** в облако (контейнер, переменные окружения, health-check)
5. Сделать продукт уровня «production»: логирование, обработка ошибок, мультиязычность, юридический дисклеймер

---

## ✅ Что реализовано (1/2)

**Мониторинг и алерты**
- Автоматическая проверка казны каждые 15 минут
- Детект покупок/продаж по порогу (`MIN_BTC_CHANGE`)
- Резервирование источников (если strategy.com недоступен → CoinGecko)
- Отслеживание BTC-пресс-релизов

**Premium-формат сигналов**
- Короткий «crypto terminal» стиль с иерархией emoji
- Авто-генерация **image-карточек** (чёрный + orange glow, логотип BTC)
- Безопасный фолбэк на текст, если генерация недоступна

---

## ✅ Что реализовано (2/2)

**Команды и аналитика**
- `/holdings` — обзор казны (₿ баланс, ≈ $, источник)
- `/stats` — средняя цена, затраты (cost basis), **Unrealized PnL**
- `/buy` — последняя покупка
- `/status`, `/site`, `/check` (админ)

**Качество продукта**
- Мультиязычность: **8 языков** (en, ru, es, de, fr, zh, ja, pt)
- Юридический **дисклеймер** для США/ЕС (`/disclaimer`, не инвест-рекомендация)
- Логирование, обработка сетевых ошибок, защита админ-команд

## 🚀 Деплой

- **Контейнеризация:** `Dockerfile` (Python 3.12-slim + шрифты DejaVu)
- **Конфигурация через переменные окружения:** `BOT_TOKEN`, `X_CHAT_ID`, интервалы, пороги
- **Health-check эндпоинт** на порту `10000` для облачного хостинга
- **Поддержка платформ:** JustRunMy.App, Render, Railway, Fly.io
- **CI/CD-готовность:** деплой по `git push`

> Бот работает 24/7, автоматически восстанавливается после сбоев.

```
GET /api/v1/whales/{id}/transactions

```

---

## 🐋 Технический план парсера

**Унифицированная модель данных** для любого источника:

```python
{
  "entity": "BlackRock IBIT",
  "type": "etf",            # company | etf | fund | gov | onchain
  "btc": 271_000,
  "change": +1_240,
  "price": 98_500,
  "source": "farside.co.uk",
  "date": "2026-05-30"
}
```

**Подход:**
1. Отдельный **парсер-модуль на каждый источник** (как сейчас для strategy.com)
2. Общий **движок алертов** переиспользует premium-карточки
3. **Расписание** опроса для каждого кита
4. Топ-10 формируется динамически по объёму холдингов

---
